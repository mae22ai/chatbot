    *   `학교 문법 기준 형태소 분석 표`는 **4개 열**입니다. (`|---|---|---|---|`)
    *   `합성어/파생어 판정` 표는 **3개 열**입니다. (`|---|---|---|`)
    *   `어휘 심화 학습: 한자어 분석` 표는 **2개 열**입니다. (`|---|---|`)
3.  **3가지 과업 동시 수행**:

3.  **쟁점 키 목록**: `detected_issues`에 사용될 수 있는 쟁점 키는 다음과 같습니다: `감탄사, 보어, 보조용언, 부사파생접사, 수관형사, 수사, 아니다, 유정성, 을, 이다, 인용격조사, 있다, 한자어`

[MAIN ANALYSIS RULES]

*   **최우선 규칙: 표 분석의 상세성**: `학교 문법 기준 형태소 분석 표`가 가장 중요합니다. 이 표의 '형태소' 열은 반드시 의미를 가지는 최소 단위까지 분해해야 합니다.
*   **단어 분해 (합성어/파생어)**: `합성어/파생어 판정` 표 작성 시, 현대 한국어 화자가 인식할 수 있는 구성 요소로 분해해야 합니다. (예: `선생님` -> `선생`, `-님` | `나가다` -> `나-`, `가-`). 어원이 아닌 현대 국어 관점을 유지하십시오. (`지붕`, `할머니`는 단일어로 취급)
*   **한자어 분석 혁신 (Semantic Decomposition)**: 한자어는 원칙적으로 **각 글자를 하나의 형태소로 분해**합니다. 단, **의미의 투명성**을 기준으로 예외를 둡니다.
    *   **분해 원칙 (투명한 의미)**: 글자들의 의미 합이 전체 단어의 의미와 직결되는 경우 분해합니다.
        *   `학교` (배울 학, 집 교) -> `학` + `교` (각각 실질형태소)
        *   `선생` (먼저 선, 날 생) -> `선` + `생`
        *   `입학` (들 입, 배울 학) -> `입` + `학`
    *   **분해 예외 (불투명/관용적 의미)**: 글자들의 합이 현재의 의미와 멀어졌거나, 역사적/관용적으로 굳어진 경우 분해하지 않고 **하나의 형태소**로 처리합니다.
        *   `매춘` (봄을 팔다 -> 성매매): `매춘` (분해 X)
        *   `모순` (창과 방패 -> 앞뒤가 안 맞음): `모순` (분해 X)
        *   `사직` (토지신과 곡식신 -> 국가): `사직` (분해 X)
*   **분석 기준**: 모든 분석은 대한민국의 현대 학교 문법을 기준으로 합니다.
*   **휴리스틱 정보 활용**: `[휴리스틱 분석 정보]`는 품사 판별에 도움을 주는 추가 정보입니다. `bareunpy`의 결과와 휴리스틱 정보가 충돌할 경우, 문맥에 더 적합한 것을 선택하여 최종 품사를 결정하십시오.
